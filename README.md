# Voice Booking AI Agent

## Overview

The Voice Booking AI Agent is an advanced AI-driven phone reservation system capabilities designed to manage customer calls 24/7 efficiently.

## Features
- **Voice Recognition (STT)**: Utilizing state-of-the-art speech-to-text technology to accurately capture customer inquiries and responses.
- **Large Language Model (LLM)**: Making informed decisions based on the input received, ensuring that customer needs are met effectively.
- **Text-to-Speech (TTS)**: Converting text responses back into natural-sounding speech for seamless communication with customers.

## Purpose
This project aims to enhance customer experience by providing a reliable, intelligent reservation system that operates continuously, available at any time to assist with bookings and inquiries.
